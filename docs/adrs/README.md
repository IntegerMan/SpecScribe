# Architecture Decision Records

This directory holds SpecScribe's Architecture Decision Records (ADRs) — short documents that
capture a significant decision, the context that forced it, the options weighed, and the
consequences we accept. They are hand-authored (not generated from `_bmad-output/`) and are
rendered into the live site by SpecScribe itself.

Each record is numbered by its filename prefix and carries a `**Status:**` line.

- [ADR 0017 — The Projection Layer's Route Space IS the IR's Path Space](0017-projection-routes-mirror-ir-paths.md) — **Proposed** 2026-07-27 (authored by Story 23.3; ADR 0009 left the projected site's *addressing* open, and ADR 0016 made it load-bearing: the IR ships whole rendered markup carrying **88,695 internal relative hrefs** across 1,049 pages. A clean extension-less route space would require rewriting every one of them, which forfeits the byte parity that made 0016's rendered-prose decision measurable. Decides: a page's route IS its IR `outputRelativePath`, verbatim, `.html` and all; **no href inside IR content is ever rewritten** — a dangling link is fixed in the emitter, never patched in the projection; the route table is generated from the manifest and **every** page prerenders, with non-migrated pages marked `data-ir-family="pass-through"` so a resolving destination is never mistaken for finished work; `crawlLinks` stays off. Two consequences accepted explicitly: Nuxt's file-based routing cannot express `.html` routes, so all IR routing goes through one `pages/[...path].vue` catch-all; and Nitro's `canWriteToDisk` substring guard silently refuses any route containing `..`, so the projection writes those pages itself. Measured by Story 23.3: `<main>` byte-identical on **189/189** migrated surfaces, IR body present verbatim on all 189, **zero** link regressions against the golden site. Cost accepted: URLs carry `.html`, and an IR path rename becomes a public URL change)
- [ADR 0018 — A Generated, Bounded, Self-Retiring Style Layer for Injected IR Content](0018-transitional-ir-content-style-layer.md) — **Proposed** 2026-07-27 (authored by Story 23.3; Story 23.2 decided the Nuxt app imports **only** a generated token bridge and never `specscribe.css` wholesale, but ADR 0016 then settled that the IR carries prose markup authored against exactly that 7,041-line monolith — leaving import-the-monolith, hand-author-7,000-lines, or ship-visually-bare, none acceptable. Decides a fourth option: `web/assets/ir-content.css`, a **second generated bridge** that is bounded by measured usage of the migrated families' markup (897 rules + 4 keyframes, **62 % smaller** than source), gated in both directions by `check:ir-content` (demonstrated red three ways, not only green), re-nested under `.ir-content` so monolith rules cannot reach a template-authored component, and **enumerated** in `ir-content.manifest.json` — that list IS the surface Story 23.4 retires. Attribute selectors deliberately do **not** bound the extraction, because they express runtime state absent from server-rendered markup and requiring them silently drops the explorer's anti-flash CSS. Extractor is hand-written against Node built-ins per ADR 0010's zero-dependency posture. Stated plainly: this **is** monolith-derived CSS and a second bridge; what makes it a transition rather than a re-import is that it is bounded, generated, scoped, counted — and that pass-through coverage, **48 %** on this repo, is reported as a number rather than implied)
- [ADR 0021 — Foreign Artifacts May Be Carried Verbatim Into the Portal, as Gated Dead-End Leaves](0021-carrying-foreign-artifacts-verbatim-into-the-portal.md) — **Proposed** 2026-07-27 (authored by Story 18.4; until now **every** portal page was composed by SpecScribe's own C# core — the only non-composed outputs were *assets*, not pages a reader navigates to. `bmad-forge-idea` renders `forge-report.html` on every exit, and that report IS the persona-objections/rationale content Story 18.4's AC #1 asks for; linking to `forged-idea.md` instead would leave every killed/clarified/in-progress idea with no destination, and re-rendering from the memlog would quietly replace the record with a lesser one. Decides: a foreign artifact may be carried **verbatim** — never rewritten, restyled, sanitized-by-transformation, or wrapped (wrapping nests one `<html>` inside another, Story 23.3's defect class); it is a **dead-end leaf**, not a portal page, and the linking page says so in words; carrying is gated on being **script-free** (no `<script>`, inline handler, `javascript:` URL, or `<iframe>`/`<object>`/`<embed>`) and **external-origin-free** and under a size cap, with any failure meaning not-written + no link + one `Skipped` diagnostic naming the gate; a carried artifact does **not** enter the SPA/webview capture, because `ExtractContentRegion` degrades a landmark-less page to nav-only and would ship a content-empty route beside a perfectly readable file. AD-1/AD-2 are **scoped, not broken** — the derived *information* still travels as one host-neutral view model; only a byte-identical copy of somebody else's document is carried. The line: SpecScribe never composes markup it did not author, and never claims authorship of markup it merely copied. Numbering: `0019` is claimed-but-unwritten by BOTH Story 18.3 and Story 22.3, `0020` is pre-claimed by Story 18.5, so `0021` is the first uncontested slot. One open question left to the owner: `Skipped` vs `Unsupported` for the gate's diagnostics)
- [ADR 0022 — Node Is a Build-Time Toolchain and a Generate-Time Runtime, Never a Shipped Toolchain](0022-node-is-a-build-toolchain-and-a-generate-time-runtime.md) — **Proposed** 2026-07-27 (authored by Story 23.5; answers the question ADR 0009 §:66/:74 left as a spike-owned unknown and Story 23.1 called "the single biggest open question in Epic 23". 23.1 stated it as a binary — client-rendered SPA (forfeits the PRD's NFR-5) *or* Node at run time (forfeits self-containment) — and that binary is **false**: it conflates the toolchain that BUILDS the projection layer with the runtime that RENDERS with it. Measured asymmetry: the build toolchain is **201.9 MB** with **14 native `.node` bindings** (Rolldown, Oxc, Rollup, LightningCSS) requiring `process.dlopen`; the shipped runtime artefact is **3.78 MB of pure JavaScript with ZERO native bindings** — 53× smaller and the only half that needs to exist at generate time. Proven by the two-IR experiment AC #4 required and nobody had ever run: ONE artefact, built with **no IR present at all**, isolated to a directory containing only `.output/`, rendered **1,056/1,056** routes of this repo and 32/33 of a different project via `SPECSCRIBE_IR_DIR`, at ~4 ms/route — a full 1,056-route pass in **6.3 s** against `nuxt generate`'s 25–30 s and the spike's ~130 s cold. Decides: the toolchain runs in CI/package time only and is never distributed; what ships is the project-independent `.output/` from `npm run build:package`; SpecScribe drives the prerender one request per route from the manifest it just emitted, never `nuxt generate`; the IR resolves at SERVER RUNTIME (verified by reading the built bundle — `process.env.SPECSCRIBE_IR_DIR` survives verbatim with all three `readFileSync` sites intact), which preserves 23.2's 1.00× payload measurement because "module scope" in a prebuilt artefact IS runtime; per channel, **npx and the VSIX already run on Node by construction** and the **standalone binary requires Node as a documented prerequisite** with an actionable startup error (owner decision — bundling a runtime at +50–100 MB/RID kept only as an escape hatch); asset URLs are rewritten page-relative because `app.baseURL: './'` is wrong for every non-root page; `web/` enters CI with drift gates + Vitest coverage; and Nuxt 3.21.9 → **4.5.1** is absorbed here (EOL 2026-07-31), holding 23.3's contract exactly at **190/190 byte-identical `<main>`, 190/190 verbatim, 0 link regressions**. Two findings recorded rather than smoothed over: a prebuilt artefact carrying prerendered pages returned **project A's dashboard for project B with HTTP 200**, because Nitro serves `public/` ahead of the SSR route — so `SPECSCRIBE_PACKAGE_BUILD=1` now empties the route table and the harness refuses such an artefact; and `DashboardSurface.vue` hard-throws on any project whose dashboard has no Hierarchy Explorer, raised to Story 23.3 rather than patched here. **AMENDS ADR 0006 §Decision's "self-contained packaging … stand[s]" clause**: the binary stays self-contained with respect to .NET, but acquires an external Node runtime prerequisite — stated rather than left to drift. ADR 0006's NFR6 ruling is **upheld in full**; nothing client-renders, and 23.3's `noScripts: true` is asserted per route by the experiment. Unblocks Story 23.4; binds 16.1/16.3/16.4)
